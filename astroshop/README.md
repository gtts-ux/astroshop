# PAI S01 - Obiekty kosmiczne

Prosta aplikacja CRUD w React. Pozwala dodawać, edytować, usuwać, wyszukiwać, filtrować i sortować obiekty kosmiczne. Lista ma maksymalnie 5 elementów na stronie.

## Uruchomienie

```bash
npm install
npm run dev
```

Dane są przechowywane tylko w stanie aplikacji i znikają po odświeżeniu strony.
